# A-Maze-ing

A browser-based maze game built with vanilla HTML, CSS, and JavaScript.

## Features

- Procedurally generated mazes using recursive backtracking (depth-first search)
- Player movement via **Arrow Keys** or **W A S D**
- **Show Solution** button that highlights the shortest path with BFS
- **New Maze** button to generate a fresh maze
- Win detection with a congratulations message

## How to Play

1. Open `index.html` in any modern browser (no build step required).
2. Navigate the blue player from the **green** entrance (top-left) to the **red** exit (bottom-right).
3. Click **Show Solution** if you get stuck — it reveals the solution path in yellow.
4. Click **New Maze** to start over with a newly generated maze.
